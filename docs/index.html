Installing: —
HOW TO FLASH
Requires Chrome, Edge, or Opera on a desktop. Safari and Firefox do not implement Web Serial. The device is fully erased before writing, so anything already on it is gone.
  • Plug the board into your computer over USB
  • Pick your hardware above — if you get it wrong the screen will be blank or scrambled, just re-flash
  • Hit FLASH MARAUDER and choose the serial port in the browser prompt
  • Wait out the write (roughly 90–150 seconds)
  • The board reboots into Marauder on its own
WHAT THIS BUILD CHANGES

This is a fork of justcallmekoko/ESP32Marauder rebuilt around the CYD battery mod. Everything upstream does, it does — plus:

  • Battery percentage in the status bar, read from a MAX17048 fuel gauge on CN1
  • GPS moved to the bottom port (P5) so the fuel gauge can have CN1
  • An inverted-display variant for the panels that need it
  • No serial CLI — the GPS UART takes those pins. Use the touchscreen.
GPS and battery are optional. The firmware probes for both at boot and simply carries on without them, so these builds are safe on a bone-stock CYD.
AFTER FLASHING — WIGLE UPLOAD

Wardrive logs can go straight from the SD card to WiGLE over WiFi, no computer in the middle. Because there is no CLI on this build, credentials are handed over on the SD card instead:

File on SD rootContents
/wigle_api_name.txtYour WiGLE API name
/wigle_api_token.txtYour WiGLE API token
  • Drop both files on the SD card and boot — they are read into settings and then deleted
  • Join a network from WiFi → General → Join WiFi
  • Upload from WiFi → General → Upload Wardrive Logs
Uploaded files get a .wigle sidecar written next to them on the card, so re-running an upload skips anything already sent.
